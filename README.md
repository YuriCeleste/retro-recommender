# Retro Recommender
Sistema de Recomendação baseado em Árvores (Trie).

Contas, pesquisas, interesses registrados nos produtos, histórico de navegação, postagens e listas do Permagram e do SuperFlix são salvos no `localStorage` do navegador. Os dados são separados por usuário e permanecem após recarregar ou reabrir a aplicação no mesmo navegador, mas não são sincronizados com outros dispositivos. Ao limpar os dados do site no navegador, eles serão removidos.

Na loja, use **Tenho interesse** para registrar um produto e incluí-lo no perfil usado pelas recomendações.

Esta autenticação é apenas demonstrativa: as contas e senhas ficam no navegador e não devem ser usadas para proteger dados reais.
