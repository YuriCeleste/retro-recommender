# Retro Recommender
Sistema de Recomendação baseado em Árvores (Trie).

Pesquisas, interesses registrados nos produtos e o histórico de navegação são salvos no `localStorage` do navegador. Esses dados permanecem após recarregar ou reabrir a aplicação no mesmo navegador, mas não são sincronizados com outros dispositivos. Ao limpar os dados do site no navegador, eles serão removidos.

Na loja, use **Tenho interesse** para registrar um produto e incluí-lo no perfil usado pelas recomendações.
